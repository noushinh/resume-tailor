# Week 7: Resume Tailor (MMV)

## 1. The Contract (I/O)

- **Input:** Two text inputs — pasted current resume text + pasted target job description.
- **Output:** Tailored resume bullet points rewritten with strong action verbs and quantified impact metrics aligned with the job requirements.

## 2. The Magical Moment

An instant, side-by-side comparison highlighting original vs. tailored bullets, clearly demonstrating the professional upgrade and matching criteria.

## 3. Scope Discipline (What We Are NOT Building)

- No user login or account creation
- No PDF/Word file uploading or parsing (plain text only)
- No multi-page document formatting or export
- No cover letter or interview prep generation

## 4. Personality / Signature Detail

Ruthless focus. Fast, immediate transformation proving high-impact tailoring in a 45-minute build without extraneous features.
